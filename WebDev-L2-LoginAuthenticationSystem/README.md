# ✅ Web Development and Designing - Login Authentication System

## 📌 Project Description
This project is a simple Login Authentication System developed to provide secure user registration and login functionality. Users can register with a username/email and password, log in using their credentials, access a protected dashboard, and log out from the system.

## 📊 Features
- User registration
- Username/email validation
- Password validation
- Minimum 8 characters with at least 1 number
- Duplicate username/email checking
- User login authentication
- Clear error message for incorrect credentials
-  Protected dashboard page
-  Redirect to login if the user is not authenticated
- Logout functionality

## 🎯 Technologies Used
- HTML5
- CSS3
- JavaScript

## 📒 Project Files
- "index.html" – Login page of the authentication system
- "register.html" – User registration page
- "dashboard.html" – Protected dashboard page
- "style.css" – Styling and responsive design
- "script.js" – Authentication, validation, and session functionality

## 🚀 Outcome
Successfully developed a simple and user-friendly Login Authentication System that supports user registration, password validation, login authentication, protected dashboard access, password hashing, and logout functionality using HTML, CSS, and JavaScript.
