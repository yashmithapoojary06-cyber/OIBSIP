# 🧮 Web Development and Designing - To-Do Web App

## 📌 Project Description

This project is an interactive To-Do Web App developed to help users manage their daily tasks easily. Users can add new tasks, edit task details, mark tasks as completed, and delete tasks. Tasks are organized into separate Pending Tasks and Completed Tasks lists.

## 📊 Features

-  Add new tasks
- Display newly added tasks in the Pending Tasks list
-  Mark tasks as completed
- Move completed tasks to the Completed Tasks list
-  Edit task text inline
-  Delete tasks from either list
-  Display pending and completed task counts
- Display task timestamps 
- Responsive and user-friendly design

## 🎯 Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JavaScript)

## 📒 Project Files

- index.html – Structure of the To-Do Web App
- style.css – Styling and responsive design
- script.js – Task management functionality

## 🚀 Outcome

Successfully developed an interactive and responsive To-Do Web App that allows users to efficiently manage daily tasks. The application supports adding, editing, completing, deleting, and storing tasks with separate pending and completed task sections.
