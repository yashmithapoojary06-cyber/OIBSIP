# 🌟 Web Development and Designing - Sir C. V. Raman Tribute Page

## 📌 Project Description

This project is a simple and responsive tribute page dedicated to Sir C. V. Raman, one of India's greatest physicists. The page presents information about his life, achievements, awards, and contributions to science.

## 📊 Features

- Tribute page dedicated to Sir C. V. Raman
- Profile image
- Biography section
- Important milestones and achievements
- Awards and honors
- Quote section
- Responsive design
- Simple and user-friendly interface

## 🎯 Technologies Used

- HTML5
- CSS3
- Java script

## 📒 Project Files

- index.html– Tribute page structure
- style.css – Tribute page design and styling
- script.js – Adds a small interactive message and page-load functionality
- Sir_CV_Raman (1).JPG – Profile image

## 🚀 Outcome

Successfully developed a simple, responsive, and informative tribute page dedicated to Sir C. V. Raman. The project presents his life, achievements, and contributions in an attractive and user-friendly format.
